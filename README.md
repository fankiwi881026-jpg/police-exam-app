# StockVision V8｜緊湊橫幅＋左側書籤
- 主視覺改為小型橫幅，沿用原本藍金圖片。
- 搜尋代號、選擇市場、更新資料、書籤分類及管理移到左側欄位。
- 主區保留股票名稱、價格、分時、日週月 K、依可取得資料顯示的資訊分頁。
- 手機版可用 Streamlit 側欄的展開／收合按鈕。
- 書籤使用 SQLite，雲端重新部署或重啟可能遺失；正式長期使用需雲端資料庫。
- 每 5 秒重繪報價區，但 Yahoo 報價快取為 5 分鐘，並非每 5 秒取得新成交價。
- 上傳所有專案檔案到 GitHub 根目錄；`.streamlit/config.toml` 保持在隱藏資料夾。
- 目前僅完成語法驗證，尚未在 Streamlit Cloud 驗證即時行情。
