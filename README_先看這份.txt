警察特考網站 v2 修復版（2026-10-25）

1. 請先備份 GitHub 專案。
2. 將本壓縮檔解壓縮，把其中檔案上傳到 GitHub 專案根目錄（index.html 必須在根目錄）。
3. 確認 GitHub 上 app.js、questions.js、index.html、style.css 的最後修改時間已更新。
4. 等待 GitHub Pages 發布，重新整理網頁（Windows Ctrl+F5）。
5. 首頁及題庫管理會出現「題庫數量統計」；按「查看各年度、等別、科目完整統計」可看詳細統計。
6. 法規頁的部分連結改成「搜尋官方法規全文」，會先開啟限定法務部官方網站的搜尋結果，並非每一條都是一鍵直達全文。

注意：未登入時，電腦匯入的本機題庫不會自動同步到手機。此修復不會更動或刪除 Supabase 資料。
